# LOLPartyOffline

英雄联盟马服（国服）用的小工具。组好队之后按个热键，好友列表里你就是离线状态，但队伍还在，该排队排队，该选人选人。

国际服有个叫 Deceive 的工具做同样的事，但它的原理在马服用不了（原因写在最后），所以这里换了个思路。只有一个 exe，常驻托盘。

## 用法

双击 `PartyOffline.exe`，托盘出现一个小圆点，然后照常开游戏。

把人拉齐之后按 `Ctrl+Alt+1`。托盘图标变灰，好友看你是离线，队伍不受影响，直接排。

中途要再拉人的话，按 `Ctrl+Alt+2` 恢复在线，拉完再按回去。

热键可以改：右键托盘 → 设置，点一下输入框直接按新组合键，保存后立即生效，不用重启。改的时候必须带修饰键（Ctrl / Alt / Shift），这条是故意限制的 —— 全局热键会抢走所有窗口的按键，只绑单个数字的话你在游戏里就打不出那个键了。

默认用 `Ctrl+Alt+1` / `Ctrl+Alt+2` 也是这个原因。

托盘图标的颜色：绿色在线，灰色离线，红色是游戏没开，黄色是连接中。

## 原理

好友看到的在线状态和队伍成员名单不是一回事，走的是两条不同的通道：

- 在线状态走聊天服务器（XMPP）
- 队伍名单走大厅服务，是服务端的对象

工具只是调了客户端自己的 `/chat/v1/suspend` 接口，把聊天连接断掉，并且不许它自动重连（`{"disconnect":true,"reconnects":false}`）。大厅那边完全没碰。队伍是服务端已经建好的东西，不会因为本地聊天断了就散掉。

这个接口本来就是客户端自己进游戏时会用的，不是谁造的后门。

端口和令牌每次都从客户端日志里现读，所以客户端重启之后这个工具不用跟着重启。

## 会不会被封

不碰游戏本身。不改文件，不改内存，不注入进程，也不碰 ACE 那套反作弊。全程在本机跑，不联网。

性质上跟你自己把状态改成「请勿打扰」差不多，都是改自己的展示状态，拿不到任何游戏内优势。

但最终怎么判定是腾讯说了算。原版 Deceive 说的「Riot 确认不会封号」是国际服的表态，马服不作数。我没法替腾讯给你保证，也没在真实账号上长期跑过。介意的话别用。

## 已知限制

断开期间拉不了新人，好友列表没了，所以得先组队再切。

队伍里的文字聊天会跟着断，走的就是那条 XMPP。

语音是 Vivox 单独走的，理论上不受影响，但我没实测过。

客户端重启后要重新按一次，断开状态不跨进程保留。

## 日志

在 `%APPDATA%\LOLDeceive\party-offline.log`。单个文件到 1MB 就滚动一次，只保留一份旧的，所以最多占 2MB 左右。上限可以在设置里改，也能一键清空。

## 系统要求

Windows，.NET Framework 4.7.2（Win10/11 自带），不需要管理员权限。

游戏装在哪个盘都能自动找到。万一没找到，把 `%APPDATA%\LOLDeceive\settings.ini` 里的 `lolRoot=` 改成你的实际路径就行。

## 致谢

思路来自 [molenzwiebel/Deceive](https://github.com/molenzwiebel/Deceive)。

它靠中间人劫持聊天服务器的 TLS 连接来改写 presence 数据包。这在国际服行得通，因为可以改客户端配置指向自己的域名，用真实签发的证书。马服这条路堵死了：配置地址锁着，客户端只认自己目录下的 `cacert.pem`，而那个文件有完整性校验，改了游戏就要你修复文件。

所以这里一行它的代码都没用，做法完全不同。但要不是先看懂了它，我不会想到在线状态是走 XMPP 而不是大厅服务。感谢原作者。
